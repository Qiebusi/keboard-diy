# 键帽工坊 · Keycap Studio

**简体中文** · [English](README.en.md)

> 在浏览器里逐键设计机械键盘键帽 —— 底色、图例、图片贴图，平面 / 3D 实时预览，一键分层拆解看清内部结构，导出图片或工程文件。

键帽工坊是一个**纯前端的键帽设计工具**：左边是键盘主视图，右边是设计面板，点一颗键就能改它的样子，改完立刻在平面图和 3D 模型上看到效果。它不联网、没有后端，适合设计键帽配色套件、试颜色搭配、给键帽贴图，或者单纯把玩机械键盘的结构比例。

技术栈：Vue 3 + Vite + Three.js（纯前端，可离线运行）。

## 1. 能做什么

| 能力 | 说明 |
|---|---|
| **键盘布局** | 内置 60%（61 键）/ 75%（87 键）/ TKL（87 键）/ 全尺寸（104 键）；支持导入 KLE 自定义布局 |
| **单键设计** | 底色、图例文字、图例颜色（可自动按底色对比配色）、图例大小 |
| **图片贴图** | 图片铺到键帽上：**仅顶面** / **十字展开包裹**（顶面 + 四壁）；缩放、旋转、位移可调 |
| **取模预览** | 实时显示该键帽的**真实十字展开纸样**，可在纸上直接拖拽移动图案，3D 同步更新 |
| **平面预览** | Canvas 2D 俯视图，与 3D 用**同一套尺寸参数**，两处外框 / 顶面逐点同尺寸 |
| **3D 预览** | 带分排高度与倾角的键帽造型，以及完整底盘：定位板、PCB、热插拔轴座、卫星轴、上下壳、脚垫 |
| **高度档案** | OEM / Cherry / SA / DSA / XDA 五种剖面档案，切换即整盘重建 |
| **分层拆解** | 像楼层一样把整盘按层展开、逐层显隐，看清键帽 / 轴体 / 上盖 / 定位板 / PCB / 下壳 |
| **导出** | 整盘 PNG（平面俯视或当前 3D 视角）、当前键帽 PNG、单键 3D 渲染图 |
| **存档** | 自动存到浏览器本地（刷新即恢复）；也可导出 / 导入 `.json` 工程文件跨设备转移 |

### 细节说明

- **键盘布局**：切换布局时已有设计会**自动迁移** —— 键名与尺寸相同的键帽保留原设计，其余用默认样式；"清空"一键恢复全盘默认。
- **图例**：留空即隐藏（如空格键）；"自动"配色按底色明暗选择深色 / 浅色文字，保证对比度；大小 0.5x ~ 1.8x。
- **图片上传（四种途径）**：面板按钮选文件、双击键帽、把图片拖到画布、Ctrl+V 粘贴剪贴板图片；支持 JPG / PNG / WebP。
- **贴图变换**：缩放 0.2x ~ 4x、旋转 ±180°、水平 / 垂直偏移；平面模式下还能直接在键帽上滚轮缩放。
- **十字展开包裹**：图片像"包纸"一样盖住顶面并延伸到四个侧壁，图案在折缝处连续；替换新图片时保留当前贴图范围设置。
- **取模预览的纸样是真实展开**（等距摊平，不是投影）：顶面纵向取 `顶面深度 / cos(倾角)` 的真实边长，四壁绕各自折缝旋转摊平 —— 所以顶面有坡度时，东 / 西壁必然是不平行的斜楔形（只有 DSA / XDA 这类 0° 倾角的才是等高梯形臂）。
- **3D 底盘**：按实物规格建模 —— 定位板 14mm 方孔 + 卫星轴过孔、热插拔轴座、卫星轴（轴座 + 穿板轴心 + Ø1.6 钢丝）、PCB 1.6mm、USB-C 母座（含口内舌片）、脚垫；外壳底面是 6° 斜坡并贴合桌面，键帽面保持水平。
- **键帽造型**：单段直斜裙边 + 锥度 + 分排倾角 + 顶面凹面，底面带轴心柱与十字插槽（大键、空格按卫星轴位置追加副轴柱）。
- **分层拆解**：自下而上六层 —— 下壳 → PCB（轴座 / 卫星轴）→ 定位板 → 上盖边框 → 轴体 → 键帽；层间距 0.4x ~ 2x 实时可调，展开有缓动动画，换键帽档案后保持展开状态；每层可单独显示 / 隐藏（例如藏起键帽看轴体、藏起下壳看腔体），隐藏的键帽不参与点选。
- **外壳键位隔板**：沿口高度铺的一层外壳塑料 —— 键位区四周、以及布局里真正没有键的位置（留白、分组空档，如 87 键 F 区与导航区之间）都是外壳本体；**相邻键帽之间没有隔板**。
- **导出尺寸**：整盘与单键均按 2 倍分辨率渲染；单键 3D 导出按长边 ≥1024px 放大渲染（键帽卡片本身很小），保证出图够清晰。

## 2. 上手流程

1. **选布局** —— 顶部切换 60% / 75% / TKL / 104，或"导入 KLE"载入自己的布局；
2. **选键帽** —— 在键盘上单击一颗键，右侧面板出现该键的设计项；
3. **做设计** —— 改底色、写图例、贴图片（双击键帽 / 拖入图片 / Ctrl+V 均可）；
4. **看效果** —— 顶部切"平面 / 3D"；3D 下可旋转缩放，还能"分层展开"逐层看结构；
5. **带走成果** —— "导出整盘 / 导出当前键帽"出图，"保存工程"存 `.json`。

## 5. 素材规格与数据说明

### 5.1 尺寸标准

- 键距标准：**1u = 19.05mm**。
- 键帽外框 = 键位格每侧内缩 `gap`（0.5mm），顶面再按 `xi`（左右）/ `zi`（前后）内缩；三者都是**固定 mm 值**，不随键宽等比缩放 —— 所以 OEM 1u 顶面 ≈ `0.643u × 0.738u`（前后比左右略深），空格等宽键的顶面 = 键宽 − 2 × (gap + xi)。
- 平面视图与 3D 模型共用同一套参数：外框、顶面矩形与 3D 的底环 / 顶环逐点同尺寸。

### 5.2 键帽高度档案（单位 mm，格式：[高度, 倾角°]）

| 档案 | F 排 | R1 数字排 | R2 Q 排 | R3 home 排 | R4 Z 排 | 底排 / 空格 |
|---|---|---|---|---|---|---|
| OEM | 11.2, 3 | 9.45, -1 | 9.0, -6 | 9.25, -9 | 9.25, -10 | 11.2, 3 |
| Cherry | 9.8, 0 | 9.8, 0 | 7.45, -2.5 | 6.55, -5 | 7.35, -11.5 | 7.35, -11.5 |
| SA | 14.89, 13 | 14.89, 13 | 12.925, 7 | 12.5, 0 | 12.925, -7 | 12.5, 0 |
| DSA | 8.1, 0（全排等高，含空格） | | | | | |
| XDA | 8.4, 0（全排等高，含空格） | | | | | |

数值取自 KeyV2（R1~R4 = row 1~4，F 排与底排 / 空格 = row 0/5），倾角按本表约定（正 = 前缘低）取反。**空格与底排（空格键所在排）必须同规格**：OEM 那一排是全板最高的 11.2mm（与 F 排等高），DSA / XDA 全排等高。3D 造型与十字展开取模预览使用同一套档案数据，保证两者展开尺寸一致。

### 5.3 工程文件格式（.json）

```json
{
  "v": 1,
  "layoutName": "60",
  "customRows": null,
  "plateColor": "#23252f",
  "profile": "oem",
  "designs": {
    "0": { "bg": "#eef0f6", "legend": "Esc", "legendColor": null,
           "legendSize": 1, "img": null },
    "5": { "bg": "#ff8800", "legend": "5", "legendColor": null,
           "legendSize": 1,
           "img": { "data": "data:image/png;base64,...", "wrap": "net",
                    "scale": 1, "rot": 0, "ox": 0, "oy": 0 } }
  }
}
```

- `designs` 以键的下标为键；`img.data` 为图片的 dataURL（含 base64），所以含图工程文件可能较大。
- `legendColor: null` 表示自动配色；`img.wrap` 为 `"top"`（仅顶面）或 `"net"`（十字展开包裹）。
- 载入时字段可缺失，缺失项用默认值补齐。

### 5.4 KLE 导入格式

- 接受 Keyboard Layout Editor 的标准 JSON：**二维数组**，字符串元素为 1u 键，对象元素为修饰（`{w, h, x, y, ...}`）；
- 也接受 `{ "keys": [...] }` 或 `{ "rows": [...] }` 包装形式；
- 导入后作为"KLE 自定义布局"出现在布局下拉框中。

## 6. 注意事项

- 图片以 base64 形式直接存入工程文件与本地存档：图片越多、越大，工程文件越大；自动存档有浏览器容量上限，超出时会静默跳过（手动"保存工程"不受影响，含大量图片时建议用工程文件保存）。
- 十字展开包裹时，图案以**顶面为中心**向四壁延伸；要控制侧壁显示的内容，通过缩放与位置偏移调节，或直接在取模预览里拖拽。
- 贴图建议用长宽比接近键帽顶面的图片，过小的图片会被放大到模糊。
- 布局切换与"应用到全部"都会保留图片（迁移按 键名 + 尺寸 匹配，未匹配到的键用默认样式）。
- 刷新页面即恢复自动存档；"清空"只重置设计、不清浏览器存档，清空后再修改会自动保存新状态。
- 导出的 PNG 不包含选中高亮等编辑态元素。

## 7. 运行与构建

环境要求：**Node.js ≥ 18**。

```bash
npm install        # 安装依赖（vue / three / vite）
npm run dev        # 启动开发服务器，终端会打印本地访问地址
npm run build      # 构建静态站点到 dist/
npm run preview    # 本地预览 dist/ 产物
```
